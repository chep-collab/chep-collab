# 👋 Hi, I'm Mercy Chepngeno

I'm a **Digital Public Infrastructure Engineer** specialising in offline-first data systems, community health data pipelines, and geospatial analytics for last-mile communities across Africa. I build systems that work where the internet doesn't — and make health data actionable for the people who need it most.

---

## 🧠 What I Do

- 🏥 Build **offline-first data collection systems** for community health worker programmes in low/zero-connectivity environments
- 🗺️ Design **geospatial analytics pipelines** for infrastructure mapping, coverage analysis, and resource allocation
- 🤖 Integrate **AI/LLM APIs** (Anthropic, OpenAI) into health data workflows to reduce reporting burden and generate programme insights
- 🔄 Build **ETL pipelines and data systems** connecting DHIS2, KoboToolbox, ODK, CommCare, and IoT sensors
- 📊 Develop **BI dashboards** (Power BI, Looker Studio, Superset) for programme managers and government stakeholders
- ⚛️ Develop **React frontends** optimised for low-bandwidth, low-literacy contexts
- 🔙 Build **secure backend APIs** for data ingestion, processing, and exchange across multi-country health programmes
